How to Read It
Check the override rules first. Then start at the top with your strongest report and follow its branch to the issuers that pull it.
The forecast table shows the model's chance of each bureau for four real lender and state cases (KPI 6). The ladder shows the move for each score step.
The Rule of Thumb
Spread applications across bureaus, apply to the strictest lender first, and use soft pulls before hard pulls.
Overrides come first: close-call states, scores under 650, or a report that already has new inquiries. Then follow the branch for the strongest report.
